DEX Event Experience Platform

Power App + Power Automate Lösung für interne Deloitte-Events

Übersicht

DEX ist eine vollständige Event-Management-Lösung, die auf Microsoft Power Platform basiert. Die Plattform ermöglicht die effiziente Verwaltung von internen Events - von der Erstellung über die Anmeldung bis zum Check-In.

Status

15+ Events erfolgreich durchgeführt. Von BR und SecO freigegeben.

Kernfunktionen

Event-Erstellung

Automatische SharePoint-Site-Erstellung inkl. Anmeldemaske. Setup in wenigen Minuten.

An-/Abmeldung

Automatische Bestätigungsmail und Kalendereintrag bei Registrierung.

Wartelisten-Handling

Automatisches Nachrücken bei Abmeldung mit Benachrichtigung.

QR-Code Check-In

Individuelle QR-Codes für jeden Teilnehmer. Check-In-Funktion für das Orga-Team.

Assistenz-Modus

Anmeldung für andere Personen möglich (varAssistancetrue).

Organizer-Zugang

Event-Auswahl gefiltert auf eigene Events. Vollständige Teilnehmerverwaltung.

Power Automate Flows

Die Geschäftslogik der Plattform wird durch mehrere Power Automate Flows abgebildet:

Registrierungs-Flow

Verarbeitet neue Anmeldungen, prüft Kapazität, erstellt Kalendereinträge.

Trigger: SharePoint Item Created

Abmelde-Flow

Verarbeitet Abmeldungen, prüft Deadline, triggert Wartelisten-Nachrücken.

Trigger: HTTP Request / App

Wartelisten-Flow

Automatisches Nachrücken von Wartelisten-Teilnehmern bei freien Plätzen.

Trigger: Flow-Aufruf

E-Mail & Kalender

Versand von Bestätigungsmails und Erstellung von Kalendereinträgen.

Trigger: Child Flow
