3. Power Automate Flows - Übersicht

Die DEX-Plattform umfasst 23 Power Automate Flows, die in fünf funktionale Kategorien unterteilt sind. Jeder Flow erfüllt eine spezifische Aufgabe und ist optimal auf die anderen Flows abgestimmt.

3.1 Event-Verwaltung

Flows für die Erstellung und Konfiguration von Events

Flow Trigger Beschreibung
NewEventAdded_SiteProvis SharePoint Item Created Hauptflow für Event-Erstellung. Erstellt SharePoint-Subsite, ruft Template-Flow auf, erstellt Outlook-Event.
ApplyTemplateB2Run Child Flow Erstellt Teilnehmerliste mit B2Run-spezifischen Feldern (Laufstrecke, Team etc.).
ApplyTemplateOtherEvent Child Flow Erstellt Standard-Teilnehmerliste für JP Morgan und sonstige Events.
EventPermission Manual Button Verwaltet Berechtigungen für Events mit eingeschränkter Zielgruppe.

3.2 Registrierung

Flows für An- und Abmeldungen von Teilnehmern

Flow Trigger Beschreibung
RegisterParticipant SharePoint Item Created Verarbeitet Anmeldungen. Prüft Kapazität, erstellt Teilnehmereintrag oder Warteliste.
DeregisterParticipant SharePoint Item Created Verarbeitet Abmeldungen. Triggert automatisches Wartelisten-Nachrücken.
CheckRegistrationStatusParticipant Power App Prüft Registrierungsstatus eines Users (registered, waitlist, not_registered).
GetWaitinglistPosition Power App Ermittelt aktuelle Position auf der Warteliste (FIFO-Prinzip).
GetParticipantEvents Power App Listet alle Events eines Users für "Meine Events"-Ansicht.

3.3 Check-In

Flows für den Check-In am Veranstaltungstag

Flow Trigger Beschreibung
Check-In SharePoint Item Created Verarbeitet manuelle Check-Ins, aktualisiert Status und Zeitstempel.
CheckInFromQRCode Power App Verarbeitet Check-Ins per QR-Code-Scan, identifiziert Teilnehmer.
EventQRCodeGenerator Manual Button Generiert QR-Codes für alle Teilnehmer und versendet per E-Mail.

3.4 E-Mail & Kalender

Flows für Kommunikation und Outlook-Integration

Flow Trigger Beschreibung
SendMailSharedMailbox Manual Button Zentrale E-Mail-Funktion über Shared Mailbox. Child Flow für andere Flows.
SendMailParticipantList Power App Massen-E-Mails an alle Teilnehmer oder nur Warteliste.
RegisterOutlookEventParticipant Manual Button Fügt Teilnehmer zu bestehendem Outlook-Termin hinzu.
CreateOutlookEventSharedMailbox Child Flow Erstellt Outlook-Termin im Kalender der Shared Mailbox.
HelperFlowMailToRegistered Manual Button Hilfsflow für spezielle E-Mail-Szenarien.

3.5 Utility & Administration

Flows für administrative Aufgaben und Datenpflege

Flow Trigger Beschreibung
Flow-Dokumentation-Export Manual Button Exportiert Flow-Definitionen für Dokumentationszwecke.
SharePoint_Batch_Update_V2 Manual Button Batch-Updates auf SharePoint-Listen via REST API.
SetPermissionForSubWeb Manual Button Setzt Berechtigungen auf SharePoint-Subsites.
UpdateAllEventsWithNewFields Manual Button Migration: Fügt neue Felder zu bestehenden Teilnehmerlisten hinzu.
CorrectOutlookID Manual Button Korrigiert fehlerhafte Outlook-Event-IDs.
SP Liste Nummerierung korrigieren Manual Button Korrigiert Nr.-Feld in Teilnehmerlisten.
