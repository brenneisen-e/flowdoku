GetParticipantEvents

"Meine Events" Abfrage

Flow-IDparticipant-events-flow-id
StatusStarted
TriggerPower App V2
KategorieRegistrierung

Beschreibung

Listet alle Events auf, für die ein User registriert ist oder auf der Warteliste steht. Wird für die "Meine Events"-Ansicht in der Power App verwendet.

Was dieser Flow macht

  • Events durchsuchen: Prüft alle aktiven Events auf Teilnahme
  • Status ermitteln: Unterscheidet zwischen registriert und Warteliste
  • Liste erstellen: Gibt eine Liste der Events mit Details zurück

Actions im Detail

1. Events laden

  • Ruft alle aktiven Events aus der Events-Liste ab
  • Initialisiert Array für Ergebnisse
ActionTypBeschreibung
Get_items (Events)SharePoint GetItemsLädt aktive Events
Initialize_variable (results)InitializeVariableArray für Ergebnisse

2. Teilnahme prüfen

  • Für jedes Event wird die Teilnehmerliste geprüft
  • Sucht nach der E-Mail des anfragenden Users
  • Bei Fund wird Event zum Ergebnis-Array hinzugefügt
ActionTypBeschreibung
Apply_to_each (Event)ForeachIteriert über Events
Get_items (Participants)SharePoint GetItemsSucht User in Teilnehmerliste
ConditionIfPrüft ob User gefunden
Append_to_arrayAppendToArrayVariableFügt Event zu Ergebnissen hinzu

3. Ergebnisse zurückgeben

  • Gibt das Array mit allen gefundenen Events zurück
  • Enthält Event-Details und Teilnahmestatus
ActionTypBeschreibung
