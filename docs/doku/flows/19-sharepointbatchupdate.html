SharePoint_Batch_Update_V2

Batch-Updates auf SharePoint-Listen

Flow-IDbatch-update-flow-id
StatusStarted
TriggerManual Button
KategorieUtility & Administration

Beschreibung

Führt Batch-Updates auf SharePoint-Listen durch. Nutzt die SharePoint REST Batch API für bessere Performance bei Massenänderungen.

Was dieser Flow macht

  • Batch-Requests erstellen: Bündelt mehrere Updates in einen Request
  • Performance: Bis zu 1000 Operationen pro Batch
  • Fehlerbehandlung: Verarbeitet Batch-Response mit einzelnen Ergebnissen

Anwendungsfälle

  • Massenaktualisierung von Feldern
  • Datenmigrationen
  • Korrekturen an vielen Einträgen

Actions im Detail

1. Daten vorbereiten

  • Lädt Items die aktualisiert werden sollen
  • Bereitet Batch-Request vor
