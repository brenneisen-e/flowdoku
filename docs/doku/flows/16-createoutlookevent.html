CreateOutlookEventSharedMailbox

Outlook-Termin im Shared Mailbox Kalender erstellen

Flow-IDcreate-outlook-flow-id
StatusStarted
TriggerChild Flow
KategorieE-Mail & Kalender

Beschreibung

Erstellt einen neuen Outlook-Termin im Kalender der Shared Mailbox. Wird bei der Event-Erstellung aufgerufen und dient als Basis-Termin für spätere Teilnehmer-Einladungen.

Was dieser Flow macht

  • Termin erstellen: Legt neuen Kalendereintrag im Shared Mailbox Kalender an
  • Details konfigurieren: Setzt Titel, Beschreibung, Start-/Endzeit, Ort
  • ID zurückgeben: Gibt die Outlook-Event-ID für spätere Referenz zurück

Actions im Detail

1. Parameter empfangen

  • Empfängt Event-Details vom aufrufenden Flow
  • Titel, Beschreibung, Start, Ende, Ort
ActionTypBeschreibung
Initialize_variablesInitializeVariableEvent-Details speichern

2. Outlook-Event erstellen

  • Erstellt Kalendereintrag via Graph API oder Outlook Connector
  • Verwendet Shared Mailbox als Kalender-Owner
  • Konfiguriert alle Event-Properties
ActionTypBeschreibung
Create_event_V4Office 365 OutlookErstellt Kalendereintrag

3. ID zurückgeben

  • Extrahiert die Event-ID aus der Antwort
  • Gibt ID an NewEventAdded_SiteProvis zurück
  • ID wird in Events-Liste gespeichert
ActionTypBeschreibung
