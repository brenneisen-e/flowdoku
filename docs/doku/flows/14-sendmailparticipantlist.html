SendMailParticipantList

Massen-E-Mail an Teilnehmer

Flow-IDsendmail-list-flow-id
StatusStarted
TriggerPower App V2
KategorieE-Mail & Kalender

Beschreibung

Versendet Massen-E-Mails an alle Teilnehmer eines Events oder nur an die Warteliste. Der Organizer kann über die Power App eine Nachricht an alle versenden.

Was dieser Flow macht

  • Teilnehmer laden: Holt alle Teilnehmer basierend auf Filter
  • E-Mails versenden: Sendet an jeden Teilnehmer individuell
  • Tracking: Zählt erfolgreich versendete E-Mails

Filter-Optionen

FilterEmpfänger
allAlle Teilnehmer (Registered + Waitlist)
registeredNur registrierte Teilnehmer
waitlistNur Warteliste

Actions im Detail

1. Parameter & Teilnehmer laden

  • Empfängt Event-ID, Betreff, Body und Filter
  • Lädt Teilnehmerliste basierend auf Filter
  • Initialisiert Zähler für Versandstatistik
ActionTypBeschreibung
Initialize_variablesInitializeVariableParameter speichern
Get_items (Participants)SharePoint GetItemsLädt Teilnehmer mit Filter
Initialize_variable (counter)InitializeVariableZähler für Versand

2. E-Mails versenden

  • Iteriert über alle Teilnehmer
  • Sendet individuelle E-Mail an jeden Teilnehmer
  • Erhöht Zähler bei Erfolg
ActionTypBeschreibung
Apply_to_eachForeachIteriert über Teilnehmer
Send_email_shared_mailboxOffice 365Sendet E-Mail
Increment_variableIncrementVariableErhöht Zähler

3. Ergebnis zurückgeben

  • Gibt Anzahl versendeter E-Mails zurück
  • Power App zeigt Erfolgsmeldung
ActionTypBeschreibung
Respond_to_a_Power_App_or_flowResponseGibt Anzahl zurück
