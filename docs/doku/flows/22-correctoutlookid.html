CorrectOutlookID

Korrektur fehlerhafter Outlook-Event-IDs

Flow-IDcorrect-outlook-flow-id
StatusStarted
TriggerManual Button
KategorieUtility & Administration

Beschreibung

Korrigiert fehlerhafte Outlook-Event-IDs in der Events-Liste. Sucht den passenden Outlook-Termin via Graph API und aktualisiert die ID in SharePoint.

Was dieser Flow macht

  • Events prüfen: Identifiziert Events mit fehlerhaften oder fehlenden Outlook-IDs
  • Termin suchen: Sucht passenden Termin im Shared Mailbox Kalender
  • ID aktualisieren: Korrigiert die OutlookEventID in der Events-Liste

Wann benötigt

  • Nach Migration oder Restore
  • Bei manuell erstellten Events
  • Nach Outlook-Synchronisierungsproblemen

Actions im Detail

1. Events laden & prüfen

  • Lädt Events ohne gültige Outlook-ID
  • Identifiziert Events die korrigiert werden müssen
ActionTypBeschreibung
Get_items (Events)SharePoint GetItemsLädt Events mit fehlender ID

2. Outlook-Termin suchen

  • Sucht im Shared Mailbox Kalender
  • Matching über Event-Titel und Datum
  • Extrahiert korrekte Event-ID
