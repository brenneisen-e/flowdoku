CheckInFromQRCode

Check-In per QR-Code-Scan mit Sub-Event-Unterstützung

Beschreibung

Verarbeitet Check-Ins per QR-Code-Scan für Sub-Events (z.B. "Vormittag", "Nachmittag"). Das Check-In-Team scannt den QR-Code des Teilnehmers mit der Power App, der Flow identifiziert den Teilnehmer per E-Mail und aktualisiert den Check-In-Status.

Sub-Event Check-In Konzept

Ein Event kann mehrere Sub-Events/Zeitslots haben. Teilnehmer können sich für jeden Slot separat einchecken. Der Status wird dabei akkumuliert:

Check-InSub-EventStatus nachher
1. Check-InVormittagCheck-In: Vormittag
2. Check-InNachmittagCheck-In: Vormittag ; Check-In: Nachmittag
3. Check-InAbendveranstaltungCheck-In: Vormittag ; Check-In: Nachmittag ; Check-In: Abendveranstaltung

3b. Compose_1 (innerhalb Apply to each)

Erstellt den neuen Status-String. Wichtig: Wenn bereits ein Check-In existiert, wird der neue Sub-Event angehängt. Ansonsten wird der bisherige Status (z.B. "QR Code versendet") komplett ersetzt.

EigenschaftWert
TypCompose
ExpressionSiehe unten
if(
  startsWith(body('Get_item')['Status'], 'Check-In:'),
  concat(body('Get_item')['Status'], ' ; Check-In: ', triggerBody()?['text_1']),
  concat('Check-In: ', triggerBody()?['text_1'])
)

Logik:

  • Wenn Status mit "Check-In:" beginnt → Anhängen: [Alter Status] ; Check-In: [Neuer Sub-Event]
  • Sonst → Ersetzen: Check-In: [Neuer Sub-Event]

Power Automate Änderung

Um die Compose_1 Action anzupassen, ersetze den aktuellen Input:

Alt (aktuell):

@{body('Get_item')['Status']};  CheckIn:@{triggerBody()?['text_1']}

Neu:

@{if(startsWith(body('Get_item')['Status'], 'Check-In:'), concat(body('Get_item')['Status'], ' ; Check-In: ', triggerBody()?['text_1']), concat('Check-In: ', triggerBody()?['text_1']))}
