SendMailSharedMailbox

Zentrale E-Mail-Funktion

Flow-IDsendmail-shared-flow-id
StatusStarted
TriggerManual Button (Child Flow)
KategorieE-Mail & Kalender

Beschreibung

Die zentrale E-Mail-Funktion der DEX-Plattform. Sendet einzelne E-Mails über die Shared Mailbox no_reply.events@deloitte.de. Wird von anderen Flows als Child Flow aufgerufen.

Was dieser Flow macht

  • Parameter empfangen: Empfänger, Betreff, HTML-Body
  • E-Mail formatieren: Fügt Standard-Header/Footer hinzu
  • Versand: Sendet über Shared Mailbox

Parameter

ParameterTypBeschreibung
toStringE-Mail-Adresse des Empfängers
subjectStringBetreff der E-Mail
bodyStringHTML-Inhalt der E-Mail
