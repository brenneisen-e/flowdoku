RegisterOutlookEventParticipant

Teilnehmer zu Outlook-Termin hinzufügen

Flow-IDregister-outlook-flow-id
StatusStarted
TriggerManual Button (Child Flow)
KategorieE-Mail & Kalender

Beschreibung

Fügt einen Teilnehmer zu einem bestehenden Outlook-Kalendereintrag hinzu. Nutzt die Microsoft Graph API um die Attendee-Liste des Events zu aktualisieren.

Was dieser Flow macht

  • Event laden: Ruft das bestehende Outlook-Event ab
  • Teilnehmer hinzufügen: Fügt E-Mail zur Attendee-Liste hinzu
  • Event aktualisieren: Speichert die aktualisierte Teilnehmerliste

Actions im Detail

1. Parameter & Event laden

  • Empfängt Outlook-Event-ID und Teilnehmer-E-Mail
  • Ruft aktuelles Event via Graph API ab
  • Extrahiert bestehende Attendee-Liste
ActionTypBeschreibung
Initialize_variablesInitializeVariableEvent-ID, E-Mail speichern
HTTP (Get Event)HttpGET /events/{id} via Graph API

2. Attendee hinzufügen

  • Erstellt neuen Attendee-Eintrag mit E-Mail
  • Fügt zur bestehenden Liste hinzu
  • Aktualisiert Event via PATCH Request
