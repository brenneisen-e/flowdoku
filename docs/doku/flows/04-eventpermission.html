EventPermission

Berechtigungsverwaltung für Events mit Zielgruppe

Flow-ID8c702f7e-b925-6769-ba71-102a65c4d0be
StatusStarted
TriggerManual Button mit Parametern
KategorieEvent-Verwaltung

Beschreibung

Verwaltet die Berechtigungen für Events mit eingeschränkter Zielgruppe. Wenn ein Event nur für eine bestimmte Audience zugänglich sein soll, konfiguriert dieser Flow die entsprechenden SharePoint-Zugriffsrechte.

Was dieser Flow macht

  • Berechtigungen entfernen: Entfernt bestehende Standardfreigaben
  • Audience berechtigen: Gewährt der definierten Zielgruppe Lesezugriff
  • Organizer berechtigen: Gewährt dem Organizer Vollzugriff

Anwendungsfall

Ein Event soll nur für eine bestimmte Abteilung (z.B. Consulting) sichtbar sein. Der Organizer gibt eine E-Mail-Gruppe als Audience an, und dieser Flow beschränkt den Zugriff entsprechend.

Actions im Detail

1. Bestehende Berechtigungen entfernen

  • Entfernt alle bestehenden Freigaben für das Event
  • Stellt sicher, dass nur autorisierte Personen Zugriff haben
ActionTypBeschreibung
Stop_sharing_an_item_or_a_fileSharePoint UnshareItemEntfernt bestehende Freigaben

2. Neue Berechtigungen setzen

  • Gewährt der Audience-Gruppe Lesezugriff auf das Event
  • Gewährt dem Organizer Vollzugriff für Verwaltung
  • Verwendet SharePoint-Freigabefunktionen

3. Abschluss

  • Bestätigt erfolgreiche Ausführung an aufrufenden Flow
