Zeitzonenkonvertierung

Alle Flows verwenden die Zeitzone Europe/Berlin (Köln) für Datumsberechnungen und Kalendereinträge.

Gemeinsame Expressions

Diese Expressions werden in mehreren Flows verwendet:

Expression Beschreibung
convertTimeZone(utcNow(),'UTC','W. Europe Standard Time') Aktuelle Zeit in deutscher Zeitzone
triggerOutputs()?['body/Event registered/Id'] Event-ID aus Lookup-Feld
body('Get_Event')?['Capacity'] Event-Kapazität abrufen
length(body('Get_Registrations')?['value']) Anzahl aktueller Anmeldungen

Fehlerbehandlung

Alle Flows implementieren ein einheitliches Fehlerbehandlungs-Pattern:

flowchart TD
    START[Flow Start] --> TRY[Try Scope]
    TRY --> |"Erfolg"| SUCCESS[Erfolg-Aktion]
    TRY --> |"Fehler"| CATCH[Catch Scope]
    CATCH --> LOG[Fehler loggen]
    LOG --> NOTIFY[Admin benachrichtigen]
  • Try Scope: Enthält die Hauptlogik des Flows
  • Catch Scope: Konfiguriert mit runAfter: failed, timedOut
  • Logging: Fehlerdetails werden in SharePoint-Liste geschrieben
