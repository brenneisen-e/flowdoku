Wartelisten-Flow

Automatisches Nachrücken von Wartelisten-Teilnehmern bei freien Plätzen.

Trigger: Child Flow Call
Aufrufer: Abmelde-Flow

Flowchart

flowchart TD
    START([Trigger: Child Flow]) --> GET_EVENT[Get Event Details]
    GET_EVENT --> GET_WAITLIST[Get Waitlist Entries
Sorted by Created Date]
    GET_WAITLIST --> CHECK_WAIT{Warteliste
vorhanden?}

    CHECK_WAIT --> |"Nein"| END_EMPTY([Keine Nachrücker])
    CHECK_WAIT --> |"Ja"| GET_FIRST[Get First Waitlist Entry]

    GET_FIRST --> PROMOTE[Promote to Registration]
    PROMOTE --> UPDATE_STATUS[Update Status:
Waitlist → Registered]
    UPDATE_STATUS --> CREATE_CAL[Create Calendar Event]
    CREATE_CAL --> SEND_MAIL[Send Promotion Email]
    SEND_MAIL --> RETURN[Return Success]

    RETURN --> END([Flow Ende])

Trigger

Child Flow / Run a Child Flow

Dieser Flow wird als Child Flow vom Abmelde-Flow aufgerufen, wenn ein Platz frei wird. Die Event-ID wird als Parameter übergeben.

Input Parameter

Parameter Typ Beschreibung
eventId Integer ID des Events mit freiem Platz
slotsAvailable Integer Anzahl freier Plätze (Standard: 1)

Aktionen

Schritt Aktion Typ Beschreibung
1 Get Event SharePoint - Get item Lädt Event-Details für E-Mail
2 Get Waitlist SharePoint - Get items Holt Warteliste sortiert nach Erstelldatum
3 Check Waitlist Condition Prüft ob Einträge vorhanden
4 Get First Expression Nimmt ersten Eintrag (FIFO)
5 Promote SharePoint - Update item Ändert Status von Waitlist zu Registered
6 Create Calendar Outlook - Create event Erstellt Kalendereintrag für Nachrücker
7 Send Email Outlook - Send email Benachrichtigt Nachrücker

Wartelisten-Logik

flowchart LR
    subgraph Waitlist["Warteliste (FIFO)"]
        W1[User A
10:00] --> W2[User B
10:15] --> W3[User C
10:30]
    end

    SLOT[Freier Platz] --> W1
    W1 --> PROMOTE[Nachrücker]

First In, First Out (FIFO)

Die Warteliste funktioniert nach dem FIFO-Prinzip. Der Teilnehmer, der sich zuerst auf die Warteliste gesetzt hat, rückt als erstes nach.

Expressions

Expression Verwendung Erklärung
triggerBody()?['eventId'] Get Event Event-ID aus Parent Flow
first(body('Get_Waitlist')?['value']) Get First Entry Erster Eintrag der sortierten Warteliste
greater(length(body('Get_Waitlist')?['value']), 0) Condition Prüft ob Warteliste Einträge hat
body('Get_Waitlist')?['value'][0]?['Email'] Send Email E-Mail-Adresse des Nachrückers

SharePoint Query

Get Waitlist Items

Die Warteliste wird mit folgendem Filter abgefragt:

Filter Query:
  Event_x0020_registered/Id eq @{triggerBody()?['eventId']}
  and Status eq 'Waitlist'

Order By:
  Created asc

Top Count:
  1
