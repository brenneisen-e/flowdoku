1. Management Summary

Projektzusammenfassung

Die DEX Event Experience Platform ist eine vollständig auf Microsoft Power Platform basierende Event-Management-Lösung für interne Deloitte-Events. Die Plattform automatisiert den gesamten Event-Lebenszyklus von der Erstellung über die Teilnehmerregistrierung bis zum Check-In vor Ort.

Kernkennzahlen

Durchgeführte Events 15+ erfolgreich abgeschlossene Veranstaltungen
Größtes Event SAP All Hands (Januar 2026)
Power Automate Flows 23 implementierte Workflows
Freigaben BR und SecO genehmigt
Entwicklungsteam Eike Brenneisen, Andreas Enk, Nils Felten

Hauptfunktionen

  • Automatisierte Event-Erstellung: SharePoint-Subsite mit Teilnehmerliste wird automatisch angelegt
  • Self-Service-Registrierung: Teilnehmer melden sich eigenständig über Power App an
  • Wartelisten-Management: Automatisches Nachrücken bei Abmeldungen
  • QR-Code Check-In: Schneller Check-In per Scan am Veranstaltungstag
  • Automatische Benachrichtigungen: E-Mail-Bestätigungen und Kalendereinträge

Technologie-Stack

  • Microsoft Power Apps (Canvas Apps)
  • Microsoft Power Automate (23 Cloud Flows)
  • SharePoint Online (Datenspeicherung)
  • Office 365 Outlook (E-Mail, Kalender)

Geplante Weiterentwicklung

  • Self-Service-Modus für Event-Erstellung ohne Admin
  • Power-User-Schulungen für Assistenzen
  • Budget: 5.000 EUR (FY25/26) + 10.000 EUR (ab FY26/27)

2. Anwendungsbeschreibung

2.1 Zweck der Anwendung

Die DEX Event Experience Platform löst das Problem der manuellen Event-Verwaltung bei internen Deloitte-Veranstaltungen. Vor der Einführung wurden Events per E-Mail, Excel-Listen und manueller Kalenderverwaltung organisiert, was zu hohem Aufwand und Fehleranfälligkeit führte.

2.2 Zielgruppen

Rolle Beschreibung Hauptfunktionen
Event-Organizer Erstellt und verwaltet Events Event anlegen, Teilnehmer verwalten, Mails senden
Teilnehmer Deloitte-Mitarbeiter Anmeldung, Abmeldung, QR-Code erhalten
Check-In-Team Orga-Team vor Ort Check-In per QR-Code oder manuell
Assistenzen Anmeldung für andere Assistenz-Modus für Stellvertretung

2.3 Unterstützte Event-Typen

2.4 Prozessablauf

flowchart TD
    START([Event-Anforderung]) --> CREATE[Event in SharePoint anlegen]
    CREATE --> AUTO[Automatische Subsite-Erstellung]
    AUTO --> TEMPLATE[Template anwenden]
    TEMPLATE --> NOTIFY[Organizer benachrichtigen]
    NOTIFY --> OPEN([Event offen für Anmeldung])

    OPEN --> REG{Teilnehmer meldet sich an}
    REG --> CAPACITY{Kapazität frei?}
    CAPACITY --> |Ja| REGISTER[Registrierung + Kalender]
    CAPACITY --> |Nein| WAITLIST[Auf Warteliste setzen]

    REGISTER --> CONFIRM[Bestätigungsmail + QR-Code]
    WAITLIST --> WAITMAIL[Wartelisten-Bestätigung]

    CONFIRM --> EVENT([Event-Tag])
    WAITMAIL --> DEREG{Abmeldung?}
    DEREG --> |Ja| PROMOTE[Warteliste nachrücken]
    PROMOTE --> CONFIRM

    EVENT --> CHECKIN[Check-In per QR oder manuell]
    CHECKIN --> END([Event abgeschlossen])
