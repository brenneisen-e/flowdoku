# DEX Brand Assets

Place official Deloitte brand assets here:

- `deloitte-logo-black.png` - Deloitte logo on transparent/white background
- `deloitte-logo-white.png` - Deloitte logo for dark backgrounds
- `dex-orb.png` - DEX Event Experience Platform orb graphic

These assets are used in:
- Email templates (EmailTemplates.ts)
- Landing page
- Event cards

Note: Upload brand assets to SharePoint SiteAssets library for use in emails,
as email clients cannot load images from SPFx bundles.
